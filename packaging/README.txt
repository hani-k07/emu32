emu32 {version} for Windows: a tool for learning 32-bit x86 assembly.
Install: run emu32-setup.exe. It needs no administrator rights and no internet.
Without installing: open the portable folder and run emu32.exe (it also works from a USB stick).
If Windows says "Windows protected your PC", the program is not signed: click More info, then Run anyway.
Help: press F1 in emu32. Questions and problems: https://github.com/hani-k07/emu32/issues
