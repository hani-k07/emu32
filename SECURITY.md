# Security policy

emu32 runs entirely on your own computer. It makes no network connections, sends no data
and runs the programs you write inside an emulated 32-bit CPU, not on your real processor.

## Supported versions

Only the latest release receives fixes. Please update before reporting a problem.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private report
instead: open the **Security** tab of this repository and choose **Report a vulnerability**.

Include the emu32 version (Help > About), your operating system, and the smallest program
or file that shows the problem. You will get a reply as soon as the maintainer can read it,
and a fix is released as a normal version with a note in [CHANGELOG.md](CHANGELOG.md).
